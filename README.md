# TONTON GAMES

İzometrik, mobil uyumlu, nokta ele geçirme odaklı bir strateji oyunu. Tarayıcıda çalışır, PWA olarak kurulabilir, Android APK olarak paketlenebilir.

## Çalıştırma
```bash
npm start        # http://localhost:8080
npm test         # oyun mantığı testleri
npm run e2e      # telefon boyutunda uçtan uca tarayıcı testi (Playwright gerekir)
npm run pwa      # PWA, çevrimdışı ve yerleşim testi
npm run balance  # yapay zeka zorluk dengesi ölçümü
```
